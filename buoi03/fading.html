Slow and fast fading

One walk down a corridor, one received power trace. Slow fading is the path loss equation itself changing as the geometry changes. Fast fading is what the other paths add on top. Turn each cause on and off and watch which part of the trace responds.

What the two curves are

  • The teal curve is Steenkiste's path loss equation and nothing else: path loss = Gt Gr λ² / (4πd)n. Walking changes d. Turning the handset would change G. Something stepping into the line of sight raises n, which is the shaded stretch. All three are slow because a body has to physically move. This is slow fading.
  • The magenta trace adds the other paths. The direct signal and one reflection off each object are summed as waves, with their real phases, so where the path lengths differ by a whole wavelength they add and where they differ by half a wavelength they cancel. Walking changes every path length, so the sum swings constantly. This is fast fading.
  • Set the reflecting objects to zero and the magenta trace collapses exactly onto the teal one. That is the whole difference between the two: fast fading needs more than one path, slow fading does not.
  • Watch the blockage with the reflections switched on. The teal curve, which is the direct path alone, falls a long way. The magenta trace falls much less, because the reflected copies are not blocked and carry the link through. A blockage only attenuates what it stands in front of, and that is one reason multipath is not purely a nuisance.
  • Stand still and both go flat. Fading is not a property of the room on its own, it is a property of the room plus movement.
  • The swing is measured over one fixed five second window, so it depends on how far you walk inside it. At a stroll it is around twenty decibels and at the fastest setting here it passes forty, because the faster walk crosses more wavelengths in the same five seconds. Stallings quotes 20 to 30 dB over a short distance, which is the same statement with the distance left implicit.

Three things worth trying

  • Start with no reflectors and no blockage: a smooth slide downhill, pure distance. Add the blockage, then add the reflectors, one cause at a time. The first two buttons do this.
  • Switch the same walk from 900 MHz to 5 GHz. The teal curve barely moves, but the magenta trace becomes far busier: the wavelength is five and a half times shorter, so the same footstep crosses five and a half times as many wavelengths. The readout counts them.
  • Raise the walking speed. Nothing about the room changed, and the same ground is covered either way, but the channel now changes that much faster per second, which is what the receiver has to keep up with.
